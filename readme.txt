# Shamiso Vushe — Portfolio

🔗 **Live Site:** [shamiso-vushe.com](https://shamiso-vushe.com) ← replace with your actual link

A personal portfolio website built with vanilla HTML, CSS, and JavaScript.

---

## Sections

- **Home** — Intro and profile
- **About Me** — Bio and resume download
- **Expertise** — Skills and technologies
- **Experience** — Internship timeline
- **Projects** — Featured projects with GitHub links
- **Education** — Degrees and certifications
- **Contact** — Contact form and socials

---

## Features

- Scroll-triggered animations on every section
- Working contact form with auto-reply (EmailJS)
- Fully responsive across all screen sizes
- Active nav link highlighting on scroll

---

## Built With

- HTML, CSS, JavaScript
- [EmailJS](https://www.emailjs.com/) — contact form
- [Google Fonts](https://fonts.google.com/) — Quicksand
